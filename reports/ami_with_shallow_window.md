# AMI with Smaller Analysis Window

AMI was calculated with smaller window that belongs to N1 and P2, respectively. N1 window was set to 80-160 ms, and P2 window was set to 170-280 ms. This window was set based on the grand averaged GFP, where maximum non-overlapping peak was placed.

Below is the best example of the analysis window for N1 and P2. Please ignore the "Correct"/"Incorrect" label, since both display the exact same data here.
